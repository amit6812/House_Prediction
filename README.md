## 🏠 House Price Prediction Project
This project is a machine learning model that predicts house prices based on specifications such as area, location, and age. The project has been deployed on **AWS EC2** and is fully **containerized using Docker**.

### 🚀 Features
* **Machine Learning Model:** A trained model designed to provide accurate house price predictions.
* **Streamlit Web App:** A user-friendly interface for users to easily enter property details.
* **Dockerized:** The entire environment is packed within a Docker container for consistency across platforms.
* **Cloud Deployment:** Hosted on an AWS EC2 instance for global accessibility.

### 🛠️ Project Structure
* **app.py:** The main file for the Streamlit application.
* **Dockerfile:** Contains instructions to build the container image.
* **requirements.txt:** Lists all necessary Python libraries (e.g., Boto3, Streamlit).
* **.gitignore:** Configured to ignore unnecessary files (such as `myenv`, `.vscode-server`).
